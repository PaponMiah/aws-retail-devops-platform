# AWS Retail DevOps Platform

An end-to-end Cloud and DevOps engineering project built around the AWS Containers Retail Store Sample Application.

## Project Goal

The goal of this project is to design and implement a complete DevOps and AWS cloud platform, covering CI/CD, artifact management, containerization, Kubernetes, Infrastructure as Code, automation, observability, and performance and cost optimization.

## Application Source

The application source is based on the open-source **AWS Containers Retail Store Sample App** developed by AWS.

Original project:
https://github.com/aws-containers/retail-store-sample-app

The application is used as the workload for this project. The primary focus of my work is the design and implementation of the DevOps and cloud infrastructure around the application.

## DevOps Journey

This repository will evolve step by step as the following areas are implemented:

- CI/CD with Jenkins
- Artifact management with Nexus Repository
- Containerization with Docker
- Container orchestration with Kubernetes
- Helm
- AWS and Amazon EKS
- Infrastructure as Code with Terraform
- Configuration management with Ansible
- Automation with Python and Bash
- Observability with Prometheus and Grafana
- Performance, scalability, and cost optimization
