# Application Source

This project uses application source code from the **AWS Containers Retail Store Sample App**.

- Upstream repository: https://github.com/aws-containers/retail-store-sample-app
- Imported version: `v1.6.3`
- Source directory imported: `src/`
- Original project: Amazon Web Services (AWS)

The application source is used as the workload for this Cloud and DevOps engineering project.

The DevOps and cloud infrastructure implemented in this repository, including CI/CD, containerization, Kubernetes, AWS infrastructure, Infrastructure as Code, automation, and observability, will be developed separately as part of this project.

The upstream application's existing deployment and infrastructure configurations may be used for reference, but are not presented as original work in this project.
